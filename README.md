# MiniMe StrongMe
Hyper-casual rogue-like tower defense (web, portrait). Lihat `docs/GAME_DESIGN.md`.

    npm install
    npm run dev      # jalankan di browser (juga bisa dibuka dari HP lewat alamat jaringan yang tampil)
    npm run build    # cek TypeScript + build ke dist/

Struktur: `src/game/` (logika), `public/assets/` (gambar), `public/fonts/` (font), `docs/` (desain).
